# 基于WebGIS的气象地质灾害监测预警管理系统
# 灾害判别与预警算法设计文档

## 一、可判别气象地质灾害类型
结合2020—2023年逐日地面气象站点观测数据，本系统可实现**降雨型滑坡、降雨型泥石流、冻融诱发型滑坡、坡面崩塌**四类典型气象地质灾害的风险判别与分级预警，均以日尺度气象因子为核心诱因指标。

## 二、数据基础与预处理方法
### 2.1 所用气象因子
- 日降水量（R）
- 前期有效降雨量（Rₑբբ）
- 日平均相对湿度（RH）
- 日最高气温、日最低气温、气温日较差
- 极大风速（V）

### 2.2 前期有效降雨量计算（权威文献支撑）
计算公式引自：
《地质灾害气象预警研究进展与发展趋势》《全国地质灾害气象风险精细化网格预报方法》

\[
R_{eff} = \sum_{i=1}^{15} \alpha^i \cdot R_{t-i}
\]

- \(\alpha=0.85\)（折减系数，行业通用）
- 计算近15天有效降水，反映土体前期含水状态

## 三、灾害判别指标与阈值设定（可直接写入论文/代码）
以下阈值均参考**自然资源部地质灾害气象预警技术规范**及核心期刊文献，适用于青藏高原东缘、四川盆地西部山地丘陵区。

# 四、分灾害判别算法设计

## 4.1 降雨诱发型滑坡判别算法
### 4.1.1 判别依据
强降雨与持续降雨导致土体饱和度升高、抗剪强度降低，斜坡失稳。
文献依据：《区域滑坡灾害降雨预警的I-D-M阈值模型研究》

### 4.1.2 判别指标与阈值
1. **当日降雨量 R**
   - 无风险：R ＜ 15mm
   - 蓝色预警（注意）：15mm ≤ R ＜ 30mm
   - 黄色预警（警戒）：30mm ≤ R ＜ 50mm
   - 橙色预警（危险）：50mm ≤ R ＜ 70mm
   - 红色预警（极危险）：R ≥ 70mm

2. **前期有效降雨量 Rₑբբ**
   - 无风险：Rₑբբ ＜ 60mm
   - 蓝色预警：60mm ≤ Rₑբբ ＜ 100mm
   - 黄色预警：100mm ≤ Rₑբբ ＜ 150mm
   - 橙色预警：150mm ≤ Rₑբբ ＜ 200mm
   - 红色预警：Rₑբբ ≥ 200mm

3. **相对湿度辅助条件**
   - 平均相对湿度 RH ≥ 85% 时，风险等级提升一级
   - RH ＜ 60% 时，风险等级降低一级（干旱条件）

### 4.1.3 最终滑坡风险等级判定规则
- 满足任一指标达到红色 → 红色预警
- 满足任一指标达到橙色 → 橙色预警
- 满足任一指标达到黄色 → 黄色预警
- 满足任一指标达到蓝色 → 蓝色预警
- 均不满足 → 无风险

## 4.2 降雨型泥石流判别算法
### 4.2.1 判别依据
短历时强降雨形成地表径流冲刷松散物源，形成泥石流。
文献依据：《显式统计预警模型下地质灾害预警方法及应用》

### 4.2.2 判别指标与阈值
1. **当日降雨量 R**
   - 无风险：R ＜ 20mm
   - 蓝色：20 ≤ R ＜ 40mm
   - 黄色：40 ≤ R ＜ 60mm
   - 橙色：60 ≤ R ＜ 90mm
   - 红色：R ≥ 90mm

2. **前期有效降雨 Rₑբբ**
   - 无风险：＜ 70mm
   - 蓝色：70 ≤ ＜ 120mm
   - 黄色：120 ≤ ＜ 180mm
   - 橙色：180 ≤ ＜ 240mm
   - 红色：≥ 240mm

3. **风速增强条件**
   - 极大风速 V ≥ 10m/s，风险等级 +1
   - V ≥ 15m/s，风险等级 +2

### 4.2.3 泥石流风险等级判定
与滑坡判定逻辑一致，取最高等级。

---

## 4.3 冻融诱发型滑坡判别算法（高海拔区域适用）
### 4.3.1 判别依据
冻融循环导致岩体破碎、土体软化，融水入渗加剧失稳。
文献依据：*Mixed Hydrometeorological Processes Explain Regional Landslide Potential*

### 4.3.2 判别指标与阈值
1. **冻融条件**
   - T_min ＜ 0℃ 且 T_max ＞ 0℃（发生冻融）

2. **气温日较差 DTR = T_max − T_min**
   - 蓝色：10℃ ≤ DTR ＜ 15℃
   - 黄色：15℃ ≤ DTR ＜ 20℃
   - 橙色：20℃ ≤ DTR ＜ 25℃
   - 红色：DTR ≥ 25℃

3. **叠加降雨条件**
   - 当日降雨 R ≥ 10mm 或 Rₑբբ ≥ 40mm
   满足则冻融滑坡风险等级提升一级

### 4.3.3 冻融滑坡风险等级
仅在**发生冻融**前提下判定，否则无冻融风险。

---

## 4.4 坡面崩塌灾害判别算法
### 4.4.1 判别依据
持续高湿度软化结构面，强降雨或大风触发崩塌。
文献依据：《地质灾害气象预警技术规范》

### 4.4.2 判别指标与阈值
1. **平均相对湿度 RH**
   - 蓝色：RH ≥ 80%
   - 黄色：RH ≥ 88%
   - 橙色：RH ≥ 93%
   - 红色：RH ≥ 97%

2. **叠加当日降雨**
   - R ≥ 25mm 时，崩塌风险 +1 级

# 五、综合风险指数计算模型（可直接写进论文）
## 5.1 模型公式
\[
H = w_1 \cdot f(R) + w_2 \cdot f(R_{eff}) + w_3 \cdot f(RH) + w_4 \cdot f(V) + w_5 \cdot f(DTR)
\]

## 5.2 权重设置（AHP层次分析法，行业通用）
- 当日降雨权重 w₁ = 0.35
- 前期有效降雨权重 w₂ = 0.30
- 湿度权重 w₃ = 0.15
- 风速权重 w₄ = 0.10
- 冻融日较差权重 w₅ = 0.10

## 5.3 综合风险等级划分
- H ＜ 0.2：无风险
- 0.2 ≤ H ＜ 0.4：蓝色（四级）
- 0.4 ≤ H ＜ 0.6：黄色（三级）
- 0.6 ≤ H ＜ 0.8：橙色（二级）
- H ≥ 0.8：红色（一级）

---

# 六、算法流程（可画流程图）
1. 读取站点逐日气象数据
2. 计算前期有效降雨量 Rₑբբ
3. 分别计算滑坡、泥石流、冻融滑坡、崩塌风险等级
4. 取各灾害最高等级为站点综合预警等级
5. 结合WebGIS在地图上分级渲染展示
6. 生成预警记录存入数据库
