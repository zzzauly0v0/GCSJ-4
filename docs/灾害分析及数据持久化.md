### 2.3 算法设计

**滑坡（→ landslide_level）**：TRIGRS + CRI

```
当日降雨 + 气温 → TRIGRS → Fs 安全系数
站点15km半径P75坡度 + 中位数海拔 → CRI = 0.40×Fs分 + 0.25×坡度分 + 0.20×降水 + 0.15×海拔
→ cri_level (1低/2中/3高/4极高)
```

关键参数：
- 坡度：站点 15km 半径内 P75（KDTree 搜索）
- 海拔：15km 半径内中位数
- CRI 阈值：≥0.35→4, ≥0.28→3, ≥0.22→2, <0.22→1

**暴雨（→ mudslide_level）**：GB/T 28592-2012（≥25/50/100/250mm）

**高温热浪（→ freezethaw_level）**：GB/T 20481-2017（≥33/35/37/40°C）

**干旱（→ collapse_level）**：干/湿季分档月累计降水阈值
