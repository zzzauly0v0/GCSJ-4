## 第二部分 · 气象站点数据接入脚本（确定执行）

### 2.1 数据现状

- 文件：`data/四川气象站点_2020.csv` ~ `2023.csv`（共 4 年）
- 编码：**GBK**（需 `encoding="gbk"` 读取）
- 粒度：**逐日**观测（约 158 个站点 × 365 天 ≈ 5.7 万行/年）
- 列（已解码）：
  ```
  区站号, 平均气温, 最高气温, 最低气温, 平均相对湿度, 最小相对湿度,
  平均气压, 最高本站气压, 最低本站气压, 平均2分钟风速, 极大风速,
  20-20时降水量, 日, 月, 年, 纬度, 经度, 测站高度, 站名, 省名, 地市名, 区县名, Unnamed: 23
  ```

> 注意：现有 `biz.biz_weather_observation` 是**逐时**表（仅供回放，约 2160 行），列也不同。
> CSV 是**逐日**数据且含 Tmax/Tmin/RH/风速 等灾害判别因子，**应建独立的日尺度表**，不复用逐时表。

### 2.2 新增数据库表（建议）

```sql
-- 站点元数据：复用现有 biz.biz_monitor_station（type='weather'），由脚本 upsert
-- 日观测时序：新建
CREATE TABLE biz.biz_weather_daily (
    id            BIGSERIAL PRIMARY KEY,
    station_code  VARCHAR(32) NOT NULL,       -- 区站号
    obs_date      DATE        NOT NULL,       -- 由 年/月/日 组合
    temp_avg      NUMERIC(5,2),               -- 平均气温
    temp_max      NUMERIC(5,2),               -- 最高气温
    temp_min      NUMERIC(5,2),               -- 最低气温
    rh_avg        NUMERIC(5,2),               -- 平均相对湿度
    rh_min        NUMERIC(5,2),               -- 最小相对湿度
    pressure_avg  NUMERIC(7,2),               -- 平均气压
    wind_avg      NUMERIC(5,2),               -- 平均2分钟风速
    wind_max      NUMERIC(5,2),               -- 极大风速
    rainfall      NUMERIC(7,2),               -- 20-20时降水量
    UNIQUE (station_code, obs_date)           -- 幂等：重复跑只更新
);
CREATE INDEX idx_wdaily_date    ON biz.biz_weather_daily(obs_date);
CREATE INDEX idx_wdaily_station ON biz.biz_weather_daily(station_code);
```

### 2.3 新增脚本：`spatial_analyse/load_weather_stations.py`

复用仓库现有风格（`psycopg2` + `DB_DSN = "host=localhost ... dbname=gcsj"`、`pandas` 读 CSV）：

1. 读取 4 个 CSV（`encoding="gbk"`），合并 `年/月/日 → obs_date`，清洗缺测值（`999999`、空串 → `NULL`）。
2. **站点 upsert**：按 `区站号` 去重，写入 `biz.biz_monitor_station`
   （`type='weather'`、`location=ST_MakePoint(经度,纬度)`、`elevation=测站高度`、`name=站名`）。
3. **日观测批量入库**：`execute_values` 批插 `biz.biz_weather_daily`，`ON CONFLICT (station_code, obs_date) DO UPDATE` 保证幂等。
4. 打印各表行数汇总。

> 入库顺序：`init.sql` → `02_sichuan_schema.sql` → `load_sichuan_boundary.py` → `load_weather_stations.py`。
