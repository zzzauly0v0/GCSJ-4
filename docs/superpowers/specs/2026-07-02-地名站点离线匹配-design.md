# 地名 → 158 站点/区县 离线匹配（Nominatim 兜底）设计

日期: 2026-07-02
范围: `spatial_analyse/tools/geo.py`（重写 `resolve_place`）、新增 `spatial_analyse/tools/db.py`、测试。

## 背景与问题

当前 `resolve_place`（[geo.py](../../../spatial_analyse/tools/geo.py)）盲信外部 geopy Nominatim：

- 国内常被限流 / 超时；
- 可能返回四川省外坐标；
- 之后 `query_station_disasters` 仅按该坐标就近取 1 个站分析。

核心诉求（已与用户确认）：**定位不可靠**。要把地名优先匹配到库内 158 个气象站及四川行政区划，未命中才回退 Nominatim，且回退结果需校验是否落在四川。

## 目标

把 `resolve_place` 从「盲信 Nominatim」改为：**先库内离线匹配 → 未命中回退 Nominatim → 校验四川范围**。绝大多数常见地名走离线、必在四川、快且不被限流。

非目标：不改 `query_station_disasters` 的就近取站逻辑；不引入前端改动；不做多候选交给 Agent 选择（用户已选「取最佳匹配」）。

## 匹配数据源（都在库内、都在四川）

1. **站名** `gis.gis_weather_station.name`（158 站，自带精确经纬度 `location`）
2. **行政区划名** `gis.gis_admin_region.name` + `center` 点（省 level=1 / 市州 level=2 / 县区 level=3）

## 匹配算法

新增纯函数 `match_place(place, candidates) -> dict | None`。

`candidates`: `[{"name": str, "lon": float, "lat": float, "source": "station"|"region", "level": int|None}]`
（station 的 level 记为 None / 或视作最具体。）

步骤:

1. **归一化**: `strip()`；行政区划候选名去掉后缀 `省 / 市 / 州 / 自治州 / 县 / 区` 再参与比较（保留原名用于返回/展示）。
2. **优先级**: 精确等名 > 站名包含（query 含候选名或候选名含 query）> 区县名包含。
3. **多命中平局取更具体者**: 先 `station`，其次行政级别数字更大（县 level=3 优先于市 level=2、省 level=1）。
   - 例: `成都都江堰` 命中 `都江堰`（县级）而非 `成都`（市级）。
4. **无命中** → 返回 `None`。

## 调用流程（`resolve_place` 重写）

签名保持可注入以便测试:
`resolve_place(place, geocode=None, candidates=None) -> dict`

1. `candidates` 为空 → 从库里查全部站名 + 行政区划名候选（数据量小，一次性拉取）。
2. `match_place` 命中 → 返回该点，`source` 为 `"station"` / `"region"`，`in_sichuan=True`，`message="ok"`。
3. 未命中 → 回退 Nominatim（现有逻辑）:
   - 网络/限流异常 → `found=False` + 异常信息（现有行为）；
   - 命中但坐标出川（四川 bbox 校验）→ `found=False`，提示补充更具体地名；
   - 命中且在川 → `found=True, source="nominatim", in_sichuan=True`。

四川 bbox（宽松包络）: `lon ∈ [97.3, 108.6]`, `lat ∈ [26.0, 34.4]`。

## 返回结构（向后兼容）

```
{found, name, lon, lat, source, in_sichuan, message}
```

- 现有字段 `found / name / lon / lat / message` 语义不变；
- 新增 `source ∈ {"station","region","nominatim"}`（未找到时可为 None）、`in_sichuan: bool`。
- `query_station_disasters` 无需改动（仍按 lon/lat 就近取站）。

## 代码组织

- 新增 `spatial_analyse/tools/db.py`: 集中 `DB_DSN` 与 `connect()`，消除 geo.py / gis_query.py 的 DSN 重复。
- `gis_query.py` 改为从 `db.py` 引入 DSN/连接（保留其 `dsn` 参数注入以兼容现有测试）。
- 改动主体在 `geo.py`。

  - geocode 抛异常 → found=False 带异常信息。
